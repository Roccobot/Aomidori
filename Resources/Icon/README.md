# Aomidori: icona finale J3 Tategaki

- aomidori-J3.svg / -dark.svg (+ -1024.png): artwork finale Default e Dark (aspetto Golden Gate simulato).
- aomidori-J3-small*.svg: versione ottimizzata per le dimensioni piccole (<=32 px).
- J3-layers/: layer per Icon Composer (vedi J3-layers/README.md). È questa la fonte della vera icona Liquid Glass.
- J3-appearances/ + aomidori-J3-appearances.png: le 6 appearance, SIMULAZIONE APPROSSIMATIVA.
- aomidori-J3-final.png: tavola di presentazione.
- AppIcon.iconset/ + AppIcon.icns: PNG piatti di ripiego (16-1024; 16 e 32 px nella versione small). Non sostituiscono il file .icon di Icon Composer.
- fj3.py, build.py, finalize.py: script di generazione (usano ../variants/lib.py e ../japan/jlib.py).
